## 1. 项目概述

### 1.1 产品定位

一款**本地优先、AI 辅助的个人工作日志与周报工具**（macOS 桌面应用）。

核心思路：用户只需在一个**统一对话入口**里随手记录（文字 / 上传 Word、PDF、图片），应用借助大模型把零散输入**自动转化为结构化的工作记录**，并在首页以 **GitHub 风格热力图 + 日历** 呈现每日工作，再据此**一键生成周报**，同时通过 **WebDAV 云盘**做多设备同步与数据备份，防止记录丢失。

### 1.2 目标用户

- 单人自用为主（个人效率工具）。
- 有「记录工作、写周报、回顾产出」需求的职场人 / 开发者。

### 1.3 核心价值

| 痛点 | 解决方式 |
|---|---|
| 工作记录散落各处、懒得记 | 一个入口，文字/文档/图片随手丢，AI 自动整理 |
| 周报撰写耗时、靠回忆 | 汇总本周记录，AI 一键生成，可编辑可导出 |
| 记了却看不到全貌 | 热力图看活跃度、日历看每日任务，直观回顾 |
| 记录容易丢失、换设备麻烦 | WebDAV 云盘自动同步 + 备份，免费且可靠 |

## 2. 技术选型（已确定）

| 维度 | 方案 | 说明 |
|---|---|---|
| 运行平台 | 仅 macOS | 首期只做 Mac 版 |
| 桌面框架 | Tauri 2 | Rust + Web 前端，安装包约 10MB、省内存、启动快 |
| 本地存储 | 文件化 JSON + SQLite 索引缓存 | 数据本体为按日分文件；SQLite 仅作查询加速，可重建、不参与同步 |
| 同步 / 备份 | WebDAV（通用配置，默认坚果云） | 见 §5 |
| 大模型接入 | OpenAI 兼容协议 + 本地 Ollama | 一套协议覆盖主流模型，见 §6 |
| 附件解析 | 本地库解析 Word/PDF + 多模态模型识别图片 | 见 §4.1 |

## 4. 功能需求

### F1 · 每日工作记录

**统一对话入口（唯一记录入口）**

- 首页固定一个输入区，采用 **WorkBuddy / 豆包式输入**：单一输入框，文字直接键入，图片 / 文件通过**拖拽到输入框、粘贴（⌘V，含截图粘贴）或点击输入框内图标**即可添加，**无需单独的「添加附件」按钮**。
- 支持的输入类型：
  - 纯文字输入；
  - 图片（拖入 / 粘贴 / 截图粘贴）；
  - 文件（Word .docx、PDF 等，拖入或选择）；
  - 混合输入（文字 + 多附件同框提交）。
- 已添加的附件在输入框内**以缩略图 / 文件标签（chip）内联显示**，可单独移除。
- 输入区提供**模型选择器**（同 WorkBuddy 对话）：下拉选择 / 切换**已在 F4 配置的大模型**，本次记录用所选模型处理；默认取设置中「记录转化」的默认模型。
- 提交后，附件先做**本地解析**：
  - Word / PDF → 提取文本（本地库解析，不依赖云端）；
  - 图片 → 调用多模态模型识别 / OCR 提取内容（含识别其中的流程图）。
- 解析出的内容连同文字，交给**大模型转化**为结构化工作记录。
- **附件定位**：附件仅是转化的「一次性原料」——处理完成后**不进入备份 / 同步**（云端只备份转化后的记录内容）；原文件在本地保留短期临时副本（可配置自动清理），便于必要时回溯或重新解析。

**AI 转化输出（结构化记录）**

每条记录转化后包含以下字段（用户可编辑，AI 仅为辅助）：

| 字段 | 说明 |
|---|---|
| 一句话摘要 | 本条记录做了什么 |
| 任务列表 | 拆分出的具体事项 |
| 标签 / 分类 | 如：开发、会议、文档、沟通、调研等（可自定义） |
| 产出物 / 成果 | 交付了哪些东西 |
| 流程图 | 关键流程 / 逻辑的可视化展示（见下） |
| 待办 / 明日计划 | 可选，提取的后续行动项 |

**流程图展示**

- AI 转化时识别内容中的**关键流程 / 逻辑关系**，生成流程图（以 Mermaid 描述存储，前端渲染为可交互图）：
  - 文档 / 图片中已有的流程图 → 多模态模型识别并结构化；
  - 文字描述中的步骤 / 流程 → AI 自动提炼生成。
- 记录中可**查看、缩放、编辑**流程图；生成周报时一并带入。

- **人机协作原则**：AI 产出先展示为「待确认」状态，用户确认后才正式入库；支持手动增删改。
- 记录按**自然日**聚合，同一天可有多条记录。
- 支持对历史记录二次编辑、追加、删除（删除进回收站，可恢复）。

### F2 · 每周周报生成

- 选定周范围（默认本周一至周日），汇总该周所有结构化记录。
- 大模型生成周报，包含板块：
  - 本周完成事项；
  - 关键成果 / 亮点；
  - 问题与风险；
  - 下周计划。
- 提供周报**模板**（简洁版 / 详细版，可扩展）。
- 输出格式：默认 **Markdown**；提供 **一键导出 Word（.docx）/ PDF**。
- 生成后允许**手动编辑**，再导出。

### F3 · 热力图 + 日历（首页可视化）

**页面上方：热力图（GitHub 贡献图风格）**

- 一年 53 周 × 7 天网格，颜色深浅表示当日工作活跃度。
- 活跃度计算（加权）：当日记录条数 + 任务数 + 内容字数。
- 支持切换年份；鼠标悬停显示当日摘要；点击某天联动下方日历定位到该天。
- 配色为单色渐变（如绿/蓝），清晰表达活跃程度。

**页面下方：日历视图**

- 月视图日历，每天格子显示：记录条数 / 任务数 / 摘要关键词。
- 点击某天 → 展开查看该天全部结构化记录（可编辑）。
- 与热力图**双向联动**。

### F4 · 大模型配置

- 配置**在软件内「设置」界面图形化完成**（无需改配置文件），包含以下能力：
- 支持 **OpenAI 兼容协议**（统一配置 Base URL + API Key + 模型名），内置主流服务商**预设模板**：
  OpenAI、DeepSeek、通义千问（DashScope）、Kimi（Moonshot）、智谱 GLM、豆包、SiliconFlow 等。
- 支持**本地 Ollama**（`http://localhost:11434`），无需联网、数据不出本机。
- 支持配置**多个模型**，并分别为「记录转化」「周报生成」指定默认模型。
- **记录入口模型切换**：记录输入框提供模型选择器，实时列出已配置模型，可随时切换本次使用的模型。
- 提供**连通性测试**按钮。
- **API Key 安全**：存储于 macOS Keychain，不明文落盘。

### F5 · 备份与同步（WebDAV）

**目标**：防丢失 + 多设备同步，两者用同一套 WebDAV 机制实现。

- **配置界面**：在软件内「设置 → 备份」图形化配置——WebDAV 地址 + 账号 + 应用密码 + 同步频率 + 手动同步按钮；默认预填坚果云，可切换 InfiniCLOUD / 其他任意 WebDAV 服务。
- **备份范围**：仅备份**转化后的结构化记录**（记录 JSON + 周报 + 设置）；**附件原文件不备份**。
- **同步策略**：本地为主、增量同步。
  - 时机：应用启动时、定时（可配置，默认每 5 分钟）、关闭时、手动触发。
  - 逻辑：拉取远端清单 → 对比本地（路径 + 哈希 + 修改时间）→ 本地新增/修改的上传、远端新增/修改的下载。
- **冲突处理**：同一文件两侧均修改时，按「最后修改时间晚者胜出」（LWW），被覆盖版本保留为 `.conflict` 备份文件。
- **首次全量同步**：显示进度提示。
- **状态提示**：展示上次同步时间、结果、待同步数量。
- **恢复能力**：新设备 / 重装后，登录 WebDAV 即从云端拉回全量数据。
- **离线可用**：断网时正常记录，联网后自动补齐。

## 5. 备份方案结论（免费）

| 服务 | 免费额度 | 结论 |
|---|---|---|
| 坚果云（默认） | 上传 1GB/月、下载 3GB/月、空间不限 | 国内稳定、中文界面，文字记录充足 |
| InfiniCLOUD | 20GB、无上传下载流量限制 | 附件多时更宽裕，国内可注册、稳定性一般 |
| Cloudflare R2 | 10GB、零下载费 | 需绑卡、配置复杂，个人日志偏重 |

**最终决定**：通用 WebDAV，默认坚果云；**不做 Git 版本历史**（保持简单，一套 WebDAV 足够）。**备份范围仅含结构化记录与周报，附件原文件不备份**（附件为一次性原料，见 F1）。

> 说明：本方案下「同步」与「备份」合一——云端全量副本即备份，多设备指向同一 WebDAV 即同步。

```
settings/                 // 应用配置（不含密钥，密钥存 Keychain）
```

## 7. 非功能需求

- **数据安全 / 隐私**：本地优先，断网可用；API Key 存 Keychain；附件仅在用户显式提交时交给所选大模型处理，处理后原文件不进入云端备份。
- **可靠性**：删除进回收站可恢复；同步失败不覆盖本地数据；写文件采用「临时文件 + 原子重命名」避免损坏。
- **性能**：热力图、日历切换流畅；大附件解析不阻塞主界面。
- **可维护性**：数据文件化、版本可迁移；日志与错误提示清晰。

## 9. 待定与风险项

- [ ] Word / PDF 复杂排版、扫描件（无文字层）的解析准确率——扫描件需 OCR，效果待验证。
- [ ] 图片内容识别依赖支持视觉的多模态模型，需用户在 F4 中配置相应模型。
- [ ] 坚果云免费版 1GB/月上传上限，附件量大时可能触顶（届时提示切换 InfiniCLOUD）。
- [ ] 数据格式升级 / 迁移方案（跨版本兼容）。
- [ ] 是否增加标签体系、周报自定义模板等扩展，待 MVP 后评估。
