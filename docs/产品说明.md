# 工作日迹 WorkTrace

本地优先、AI 辅助的个人**工作日志与周报**桌面工具（macOS / Windows）。

> 把「记工作、出周报」压到最低成本。记录、回顾、汇报，一条工作台全搞定。

从随手一句话到你需要的周报，无需在多个软件之间来回切换。**统一输入框记录 → AI 结构化 → 热力图 / 日历回顾 → 一键周报 → 云盘备份**，记录不丢失、多设备可同步。

## 一句话流程

**统一输入框记录 → AI 转为结构化记录（摘要 / 任务 / 待办 / 成果）→ 热力图 / 日历可视化回顾 → 一键生成周报 → WebDAV 云盘同步备份**

## 核心流程

一条线走完「记工作 → 出周报」的全链路：

**1 · 记录工作**
文字直接键入，图片、Word、PDF 拖拽或粘贴即可。AI 自动拆分为结构化记录（时间 / 工作内容 / 进度结果 / 相关人员 / 备注下一步）。待办则拆成清晰可勾选的待办项（含时间地点 / 注意点）。

**2 · AI 结构化**
接入你配置的大模型（OpenAI 兼容 / 本地 Ollama），把口语化的输入整理成规整的工作记录，忠实原文不编造。

**3 · 可视化回顾**
GitHub 风格年度热力图 + 月历双向联动，每天的工作量一目了然；点击日期弹出当日详情。

**4 · 一键周报**
汇总本周所有记录，AI 按语义智能分类生成四板块周报（完成事项 / 关键成果 / 问题风险 / 下周计划），Markdown 默认，可导出 Word / PDF，也支持在线编辑修改。

**5 · 云盘备份**
WebDAV（坚果云 / InfiniCLOUD / 自建），支持多账号切换、自动认证，记录与周报随时跨设备同步。

## 核心功能

为「记工作、写周报」打磨的细节，每一个功能都来自真实的工作汇报痛点。

### 统一记录入口

WorkBuddy 式单一输入框：文字直接键入，图片 / 文件靠拖拽、粘贴或框内图标添加。不需要学习复杂的表单，想到什么记什么。

### AI 智能拆分

记录与待办分别用不同的专业提示词：工作记录按「职场助理」拆成时间 / 工作内容 / 进度结果 / 相关人员 / 备注下一步；待办按「日程秘书」拆成可勾选项（含时间地点 / 注意点）。

### 附件解析

Word（.docx）、PDF 本地提取文本；图片走多模态视觉模型识别内容。会议通知、聊天截图、文档，拖进来就能归入记录。

### 大模型多模型配置

OpenAI 兼容协议 + 本地 Ollama，支持配置多个模型并按用途分工（记录转化 / 周报生成 / 图片识别），每个模型可单独测试连通性。

### 周报智能分类

先进的周报提示词会结合「时间 + 语义」判断每件事的归属——本周四参加的活动归入本周完成事项，未来待办才进下周计划，不再机械错分。

### 周报在线编辑

AI 生成的周报可直接在界面用 Markdown 编辑、保存、再导出，不满意的地方自己改。

## 为什么选它

把「好用的工作日志工具」做到位。

- **本地优先**：记录与周报只存在你的电脑上（`~/Library/Application Support/WorkTrace/`），不上传第三方服务器。
- **密钥安全托管**：大模型 API Key、WebDAV 密码存 macOS Keychain 安全托管，不落明文文件。
- **跨设备同步**：配置 WebDAV 云盘后，记录与周报自动备份，多台设备保持一致。
- **记录规划两不误**：工作记录与待办分开管理，日历里用不同颜色区分，清晰明了。
- **本地文件即数据**：纯文件化 JSON 存储，数据结构透明、易迁移、可回溯。

## 适用场景

不管你是做工作汇报、项目管理、还是日常自省总结，这套工作流都能把记录这件事压到最低成本。

**职场上班族 / 研发人员**
每天在统一入口随手记几笔，周末一键生成周报，不再临时回忆、拼凑成果。

**管理者 / 项目负责人**
透过热力图和日历掌握团队工作量，周报自动归档，汇报素材随取随用。

**自由职业 / 备考党**
待办拆分让计划清晰可勾，每日进度可视化，长期坚持形成自己的成长记录。

## 本地优先 · 隐私安全

你的工作记录，永远属于你自己。工作日迹采用**本地优先**架构：所有记录、周报、附件处理都在你的电脑上完成，数据只存在本地文件目录。

只在调用 AI 能力（记录转化、周报生成、图片识别）时，才会把必要的一段文本 / 图片按需发送到你**自己配置**的大模型接口。绝不上报你的记录内容用于任何分析或训练。

- **本地文件存储**：记录、周报都是本地 JSON / Markdown 文件，透明、可备份、可迁移。
- **密钥进系统钥匙串**：API Key、WebDAV 密码存 macOS Keychain（失败降级本地，保证可用）。
- **云盘仅同步结构化数据**：备份走你自己指定的 WebDAV，仅同步记录与周报，附件这类一次性原料不同步。
