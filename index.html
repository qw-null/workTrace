常见问题

你可能想问

还有疑问？欢迎到 GitHub 提 Issue

需要一直联网才能用吗？
记录、回顾、周报编辑等核心功能完全本地运行，无需联网。只有在调用大模型做「结构化 / 周报生成」时才需要联网访问你配置的模型（也支持本机 Ollama 离线运行）。
我的工作数据安全吗？
数据默认只存在你本地（JSON / Markdown 文件），API Key 与 WebDAV 密码存入系统钥匙串。没有账号体系、没有云端数据库，你随时可整体导出。
支持哪些 AI 模型？
任意兼容 OpenAI 协议的云端模型（如 GPT 系列、国内大模型网关等），以及本机运行的 Ollama 模型。可在设置中配置多个并按用途切换、测试连通性。
如何更新到新版本？
桌面端内置更新检查，发现新版本会提示一键下载安装并重启；也可随时到 GitHub Releases 手动下载最新安装包。
