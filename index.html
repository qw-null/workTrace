本地优先 · 隐私安全

你的工作记录，永远属于你自己

  • 本地文件存储 — 记录与周报只存在你电脑上（JSON / Markdown），透明、可备份、可迁移。
  • 密钥进系统钥匙串 — API Key、WebDAV 密码存 macOS Keychain，不落明文。
  • 按需调用 AI — 只在调用大模型时发送必要片段，绝不用于分析或训练。
  • 附件不上云 — 附件是一次性原料，仅本地临时处理并自动清理，不同步。
